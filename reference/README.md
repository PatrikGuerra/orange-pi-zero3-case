# Referência

`motorbottle-case.stp` vem de [MotorBottle/OrangePi-Zero3-3D-Print-Case](https://github.com/MotorBottle/OrangePi-Zero3-3D-Print-Case) (licença MIT).

Ele traz o modelo 3D da placa e da placa USB. O `case.py` usa as medidas dele, e o `tools/fit_check.py` usa o arquivo para checar colisões.
